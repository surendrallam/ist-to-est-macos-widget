# Privacy Policy

Last updated: 19 October 2026.

IST to EST is a macOS app, widget and website for converting India Standard Time (IST) to US Eastern Time (EST/EDT). It is built so that there is nothing to collect.

## Summary

- **No data collection.** The app, the widget and the website collect, store and share no personal data.
- **No network access.** The app and the widget make no network requests at all.
- **No analytics, no tracking, no ads, no accounts.**
- **No cookies.** The website sets no cookies and loads nothing from third parties.

## The app and the widget

- Everything is calculated on your Mac, from the time zone database and the region settings (such as the 12- or 24-hour clock) built into macOS.
- The app and the widget extension run in the App Sandbox without the network entitlement, so macOS does not let them connect to the internet.
- They contain no analytics, crash reporting or advertising code, and no third-party SDKs.
- They save no settings, history or files. Times you enter in the converter stay in memory and are gone when you quit the app.
- The app writes to the clipboard only when you click **Copy**, and it never reads the clipboard.
- The **Website**, **Source code** and **Report an issue** links in the app open in your web browser. Those websites are covered by the website section below and by GitHub's privacy statement.

If you have turned on **Share with App Developers** or similar options in **System Settings › Privacy & Security › Analytics & Improvements**, macOS shares that data with Apple under [Apple's privacy policy](https://www.apple.com/legal/privacy/). This project does not receive it.

## The website

The website at <https://surendrallam.github.io/ist-to-est-macos-widget/> is a static page hosted on GitHub Pages.

- It sets no cookies and uses no local storage.
- It has no analytics, tracking pixels, embedded videos, web fonts from other sites or other third-party content.
- The converter runs entirely in your browser. When you use it, the page updates its own address (for example `?from=ist&t=2026-01-15T09:00`) so you can bookmark or share a conversion. That address is sent to the server only if you open or reload such a link.
- Like any web host, GitHub receives the technical information that your browser sends with each request, such as your IP address. GitHub may log visitor IP addresses for security purposes. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Downloads, issues and source code

Releases are downloaded from GitHub, and issues and pull requests are hosted on GitHub. When you use GitHub, the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) applies. The maintainer sees what you post, such as issues, comments and any private report you send. Apart from that, the maintainer sees only aggregate statistics from GitHub, such as release download counts, which are not linked to individual people.

## Children

The app and the website collect no information from anyone, including children.
