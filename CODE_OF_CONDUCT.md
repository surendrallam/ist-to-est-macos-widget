# Code of Conduct

IST to EST adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The full text at that link applies to everyone who takes part in this project: in issues, pull requests, discussions, commit messages, reviews and any other project space. It also applies when someone represents the project elsewhere.

## In short

We want a welcoming, harassment-free project for everyone, whatever their age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

Expected behaviour:

- Be kind and patient, especially with newcomers and with people writing in a second language.
- Respect different viewpoints and experiences. Disagree with ideas, not people.
- Give constructive feedback and accept it gracefully.
- Take responsibility for mistakes, apologise to those affected, and learn from them.
- Focus on what is best for the people who use the app and for the project as a whole.

Not acceptable:

- Sexualised language or imagery, and unwelcome sexual attention or advances.
- Trolling, insulting or derogatory comments, and personal or political attacks.
- Public or private harassment.
- Publishing someone else's private information, such as a physical or email address, without their explicit permission.
- Any other conduct that could reasonably be considered inappropriate in a professional setting.

## Reporting

If you experience or witness unacceptable behaviour, please report it privately to the maintainer. Do not report it in a public issue:

- **Private report on GitHub:** open a [private report](https://github.com/surendrallam/ist-to-est-macos-widget/security/advisories/new) through the repository's private vulnerability reporting form and start the title with "Code of conduct". Only you and the maintainer can see it.
- **Contact the maintainer** through the GitHub profile [@surendrallam](https://github.com/surendrallam).
- **Report the content to GitHub:** you can report a comment, issue or user to GitHub staff with the **Report content** option in the comment menu (`…`) or on the user's profile.

Please include links to the comments, issues or pull requests involved, and any context that helps. Every report is reviewed promptly and handled as confidentially as possible. The privacy and safety of the person reporting are respected.

## Enforcement

The maintainer is responsible for enforcing this code of conduct. Possible actions follow the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): a private correction, a warning, a temporary ban, or a permanent ban from the project. The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code of conduct.
